  # chrysg.com

  Personal Website and Blog of Chrys Gonsalves
</div>

This site is self-hosted (behind [Cloudflare](https://www.cloudflare.com)) and built with [NextJS](https://nextjs.org) and makes use of API routes to handle submissions from the email contact form.

Email from chrysg.com is sent via [Amazon SES](https://aws.amazon.com/ses) (one of the cheapest for transaction email with a generous free tier).
